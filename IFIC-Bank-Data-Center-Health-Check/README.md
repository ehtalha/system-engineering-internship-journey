# IFIC Bank – Data Center Visit & CSSS CCTV Health Check

## 📌 Overview

This repository documents my practical learning experience during a **data center visit to IFIC Bank** on **23 August 2026**, as part of my internship at **Express Systems Limited** in the **System Engineering Team**.

During this visit, I accompanied a senior system engineer who was assigned to perform a **CSSS CCTV Health Check (CSSS CCTV HC)**. The purpose of my participation was to observe the professional workflow and gain practical knowledge of enterprise server management and health-check procedures.

> **Note:** This documentation is based on my learning and observations during the activity. Sensitive information such as management IP addresses, usernames, passwords, customer information, and confidential server details has intentionally not been included.

## 🔧 Activities Observed

During the visit, I observed the following workflow:

1. Completed the required verification and security procedures for entering the data center.

2. Observed the physical server infrastructure.

3. Identified seven Dell PowerEdge R750xs servers associated with the environment.

4. Observed the connection of an Ethernet cable to the server's **iDRAC management port**.

5. Accessed the server's management interface using its authorized management IP.

6. Logged into the iDRAC dashboard using authorized credentials under senior supervision.

7. Navigated to:

   **Maintenance → SupportAssist**

8. Collected the required diagnostic information, including:

   * Storage Log
   * Debug Log

9. Downloaded the generated diagnostic package in ZIP format.

10. Repeated the process for all seven servers.

11. The collected log packages were retained for subsequent analysis and preparation of the health-check report.
