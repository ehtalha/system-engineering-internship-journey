Veritas Access Software Upgrade Monitoring

Overview

During my System Engineering internship, I observed a senior System Engineer performing a Veritas Access software upgrade using MobaXterm.

The system was being upgraded from version 8.3 to version 8.5.

Activity Details

The following command was used to check the upgrade status:

system software upgrade-status

At the time of observation, the upgrade status was:

RUNNING

The system was performing tasks such as:

Preparing for the upgrade

Syncing the upgrade package across cluster nodes

Validating the upgrade package

Monitoring the upgrade status

Key Learning

From this activity, I learned the basic concepts of:

Veritas Access

Software upgrade

Cluster and cluster nodes

Upgrade package synchronization

Upgrade status monitoring

MobaXterm and remote system management

What I Learned

This observation helped me understand how a System Engineer monitors a software upgrade in an enterprise environment. It also gave me a basic understanding of cluster-based systems and Veritas Access.
